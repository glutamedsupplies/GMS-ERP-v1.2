# iOS Foundation

This folder contains the first SwiftUI source foundation for the `GMS ERP` App Store build.

Current scope:

- SwiftUI app shell for phone and tablet layouts
- Existing backend contract reuse through `https://gmserp.com`
- Company-aware login, session restore, runtime branding, logout, and account deletion
- Placeholder handoff points for Firebase Google login and Sign in with Apple token exchange

Next steps:

1. Create an Xcode project on a Mac and add these source files to the target.
2. Attach Firebase iOS SDK for Google and Apple provider token acquisition.
3. Replace the placeholder workspace cards with native employee, head-admin, and super-admin modules by beta wave.
